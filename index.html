Налаштування API

Введіть ваш Gemini API ключ (зберігається в localStorage). Для Generative API Google зазвичай потрібен OAuth Bearer токен — перевірте ваш доступ.

Якщо ваш бекенд вимагає іншого формату (наприклад, proxy), адаптуйте код у секції JS.

Підтримуються JPG/PNG. Кожне фото буде конвертовано в base64 перед відправкою.
